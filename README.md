# Hypotension burden & postoperative organ injury — reproduction package

All materials are in [`github_upload/`](github_upload/): mixed Python/R analysis
code and supporting materials.
See [`github_upload/README.md`](github_upload/README.md) for the data dictionary,
file-to-table/figure mapping and third-party DUA statement.

Files in `code/` without an extension are R scripts; numbered filenames are
historical and all scripts correspond to manuscript v13. No individual-level
records are included; source databases are governed by third-party data use
agreements.
